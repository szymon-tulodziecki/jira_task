Witajcie w naszym wspólnym projekcie. Celem tego zadania jest nauka współpracy przy użyciu systemu Git (GitHub) oraz realizacja zadań przypisanych w systemie Jira.

Każdy z Was ma przypisane konkretne zadanie (np. dodanie nagłówka, stopki czy formularza). Zbudujemy tę stronę z małych modułów, a na końcu połączymy to w jedną, działającą całość.

## Jak pracujemy (Workflow)

Aby nie nadpisać sobie nawzajem kodu i uniknąć konfliktów, pracujemy na Forkach i Pull Requestach. Oto schemat działania dla każdego zadania:

1. **Sforkuj to repozytorium** na swoje konto GitHub (przycisk Fork w prawym górnym rogu).
2. **Sklonuj swojego forka** na dysk lokalny (`git clone <link-do-twojego-forka>`).
3. **Utwórz nowy branch** dla swojego zadania, np. `git checkout -b feature/header` (zgodnie z instrukcją w zadaniu).
4. **Wklej swój kod** w odpowiednie miejsce w pliku (`index.html` lub `script.js`).
5. **Zrób commit i push** na swój branch (`git add .`, `git commit -m "..."`, `git push origin nazwa-brancha`).
6. **Utwórz Pull Request (PR)** z Twojego forka do gałęzi main w tym głównym repozytorium.

Prowadzący przejrzy Twój kod i scali go (Merge) z główną wersją projektu.

## Zasady Gry

* **Nie modyfikuj kodu innych.** Zastępuj tylko te komentarze, które są przypisane do Twojego zadania.
* **Nie zmieniaj nazw klas w HTML.** Style (plik `style.css`) są już przygotowane. Jeśli zmienisz nazwę klasy, element na stronie nie będzie wyglądał poprawnie.
* **Brak bezpośrednich pushy do main.** Główna gałąź jest zabezpieczona. Zmiany wprowadzamy wyłącznie przez Pull Requesty.
* Zawsze sprawdzaj lokalnie w przeglądarce, czy Twój element wyświetla się poprawnie przed utworzeniem PR.
